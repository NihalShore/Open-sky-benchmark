04 / METHOD

Read the spectrum

Compare official wavelength-channel previews while keeping the product and preview provenance visible.

03 / REVIEW

Separate time from colour

Review dated NEOWISE-R single exposures as nearby catalog measurements; source association is not performed. A wavelength difference is not a multi-epoch residual.

Scientific limits

HiPS PNGs are for display only. This demo does not perform calibrated multi-epoch subtraction, PSF matching, photometric scaling, uncertainty propagation, or automated candidate classification. FITS discovery is not the same as FITS validation.
